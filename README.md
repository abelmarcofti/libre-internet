# Libre-internet
Biblioteca digital abierta con el fin de compartir recursos libres, gratuitos o públicos entre usuarios.


La biblioteca es un catálogo de enlaces, no se aloja ningún archivo en el repositorio.


## Por qué existe
Internet nos ofrece una gran cantidad de conocimiento con tan solo unos clics, pero ahora que ha crecido tanto, es fácil perderse entre tantos sitios web. Con libre-internet, quiero agrupar todos esos recursos en un solo repositorio para que cualquier usuario pueda colaborar y consultarlos, sin anuncios ni barreras de pago.


Me he inspirado en el internet de antes, con comunidades más pequeñas y personales, donde cualquiera podía colaborar y ayudar a un pequeño portal a crecer sin tener que registrarse (actualmente hay que estar registrado en github.com para proponer un recurso, pero el objetivo es añadir un formulario a la página web para que cualquiera lo haga), añadir su número de teléfono y que le añadan a una *newsletter* para llenarle el correo electrónico de publicidad.


## Qué incluye
Se pueden compartir:
- Libros
- Manuales
- Cursos
- Películas
- Documentos
- Artículos
- Cualquier página web que encaje con la filosofía del proyecto


**No está permitido añadir enlaces a sitios webs que se dediquen a la distribución de contenidos con derechos de autor sin la autorización de estos.**


Se puede compartir material con copyright siempre que se haya publicado con permiso del autor.


Se puede compartir material en cualquier idioma, recuerda indicarlo correctamente.
