# El proyecto
Biblioteca digital abierta con el fin de compartir recursos públicos entre usuarios.

## Por qué existe
El internet nos ofrece una gran cantidad de conocimiento con tan solo unos clics, pero ahora que ha crecido tanto, es fácil perderse entre tantos sitios webs. Con libre-internet, quiero agrupar todos esos recursos en un solo repositorio para que cualquier usuario pueda colaborar y consultarlos, sin anuncios ni barreras de pagos.

## Que incluye
Se pueden compartir:
- Libros 
- Manuales
- Cursos
- Películas
- Documentos
- Artículos
- Cualquier página web que encaje con la filosofía del proyecto

**No está permitido añadir enlaces a sitios webs que se dediquen a la distribución de contenidos con derechos de autor sin la autorización de estos**
Se puede compartir material con copyright siempre que se haya publicado con permiso del autor.
Se puede compartir material en cualquier idioma, recuerda indicarlo correctamente.
